# Logi
`raw/` — pliki XML z MaxiECU / Car Scanner (nazwa: RRRR-MM-DD_opis.xml).
`scripts/` — parsery Python. Oryginalne skrypty powstały w czacie i nie zostały przeniesione; przy pierwszej analizie niech Claude obejrzy przykładowy XML i napisze parser od nowa.
Pamiętaj: 1,8–4,6 Hz, maks. 3–4 kanały na sesję; sprawdzaj regenerację DPF (Pol1/Pol2).
